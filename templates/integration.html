Le SDK JavaScript et l'API REST d'EptaAdmin permettent de lire les données de vos workspaces (colonnes et valeurs) depuis n'importe quel projet externe — un script, un backend, une étape de build frontend. L'accès est en lecture seule et respecte exactement les mêmes permissions que votre compte.

1. Obtenir une clé API

Chaque clé porte les mêmes permissions que votre compte : elle ne peut lire que les workspaces dont vous êtes déjà membre. Elle n'est affichée qu'une seule fois à sa création — copiez-la immédiatement.

Générer une clé depuis mon profil

2. Installer le SDK JavaScript

Le package est publié sur le registre npm et versionné automatiquement depuis ce dépôt.

shell 
npm install eptaadmin-sdk

Pour tester un changement pas encore publié, pointez plutôt vers le dossier local : "eptaadmin-sdk": "file:../path/to/EptaAdmin/sdk/js" dans votre package.json.

3. Démarrage rapide

quickstart.js 
import { EptaAdminClient } from "eptaadmin-sdk";

const client = new EptaAdminClient({
  apiKey: process.env.EPTAADMIN_API_KEY,
  baseUrl: "https://votre-instance.example.com",
});

const workspaces = await client.listWorkspaces();

const dataSources = await client.listDataSources("{{.ExampleWorkspaceSlug}}");

const data = await client.getDataSource("{{.ExampleWorkspaceSlug}}", "{{.ExampleDataSourceSlug}}");
console.log(data.columns);

Modèle de données : colonnes indépendantes

EptaAdmin stocke chaque colonne comme une liste indépendante de valeurs — il n'y a aucune correspondance ligne à ligne garantie entre les colonnes. getDataSource() renvoie exactement cette forme :

{
  "name": "Clients",
  "slug": "clients",
  "columns": {
    "nom": ["Jean Dupont", "Marie Curie"],
    "email": ["jean@example.com", "marie@example.com"]
  }
}

Si votre projet a besoin d'enregistrements alignés par ligne, reconstruisez-les vous-même à partir des colonnes que vous savez destinées à correspondre (par exemple par index) — EptaAdmin ne garantit pas cet alignement.

Référence du SDK

Cliquez sur une méthode pour voir un exemple d'appel et de réponse.

exemple 
const workspaces = await client.listWorkspaces();
console.log(workspaces);
// [{ name: "{{.ExampleWorkspaceName}}", slug: "{{.ExampleWorkspaceSlug}}", role: "{{.ExampleWorkspaceRole}}" }]
exemple 
const dataSources = await client.listDataSources("{{.ExampleWorkspaceSlug}}");
console.log(dataSources);
// [{ name: "{{.ExampleDataSourceName}}", slug: "{{.ExampleDataSourceSlug}}" }]
exemple 
const data = await client.getDataSource("{{.ExampleWorkspaceSlug}}", "{{.ExampleDataSourceSlug}}");
console.log(data.columns);
/*
{{.ExampleColumnsJSON}}
*/
exemple 
// "wsSlug/dsSlug/column" -> toute la colonne
const values = await client.getValue("{{.ExampleWorkspaceSlug}}/{{.ExampleDataSourceSlug}}/{{.ExampleColumnKey}}");
console.log(values);
// {{.ExampleColumnValuesJSON}}

// "wsSlug/dsSlug/column/index" -> une seule valeur
const oneValue = await client.getValue("{{.ExampleWorkspaceSlug}}/{{.ExampleDataSourceSlug}}/{{.ExampleColumnKey}}/0");
console.log(oneValue);
// {{.ExampleColumnFirstValueJSON}}

API REST (autres langages)

Sans le SDK JS, appelez directement l'API — n'importe quel langage capable de faire une requête HTTP fonctionne, avec le même en-tête d'authentification.

GET /api/v1/workspaces
GET /api/v1/workspaces/{slug}/datasources
GET /api/v1/workspaces/{slug}/datasources/{dsSlug}
GET /api/v1/workspaces/{slug}/datasources/{dsSlug}/columns/{key}
GET /api/v1/workspaces/{slug}/datasources/{dsSlug}/columns/{key}/{index}
curl 
curl -H "Authorization: Bearer $EPTAADMIN_API_KEY" \
  https://votre-instance.example.com/api/v1/workspaces/{{.ExampleWorkspaceSlug}}/datasources/{{.ExampleDataSourceSlug}}

Gestion des erreurs

Une requête en échec — clé invalide, workspace inaccessible, ressource introuvable — répond en JSON avec un champ error et le code HTTP correspondant (401, 403, 404...). Le SDK convertit ça en exception typée :

errors.js 
import { EptaAdminClient, EptaAdminError } from "eptaadmin-sdk";

try {
  await client.getDataSource("{{.ExampleWorkspaceSlug}}", "does-not-exist");
} catch (err) {
  if (err instanceof EptaAdminError) {
    console.error(err.status, err.message); // 404 "Source de données introuvable."
  }
}
